# 🌾 APLIKAGRO — Motor Agro del Campesino

> *"La tecnología no decide por el campesino. Le permite decidir mejor."*

---

## 📖 Descripción

**APLIKAGRO** es una aplicación web universal para productores rurales que integra de forma holística:
`Tierra` + `Agua` + `Clima` + `Cultivos` + `Animales` + `Trabajo` + `Recursos` + `Economía` + `Mercado` + `Conocimiento campesino` + `Ciencia` + `Evidencia` + `Tecnología` + `Aprendizaje`.

---

## 🚀 Características Principales

- 📊 **Dashboard Principal**: Semáforos visuales y tarjetas de información clave (KPIs).
- 📏 **Unidades del Campo**: Conversor de medidas tradicionales (varas, cordeles, caballerías) a sistema internacional.
- 🗺️ **Mapa de la Finca**: Visualización de parcelas, potreros y zonas (preparado para integración GPS/drones).
- 🧪 **Ficha de Suelo**: Registro de pH, nutrientes y materia orgánica con distinción de datos medidos/estimados.
- 💧 **Gestión del Agua**: Balance hídrico dinámico y alternativas de riego.
- 🔄 **LOOPHH**: Motor de interacciones sistémicas entre componentes de la finca.
- 📸 **Lector de Fotos**: Análisis preliminar con niveles de confianza (preparado para IA).
- 💰 **Economía**: Cálculo de márgenes, costos operativos y rentabilidad.
- 🔮 **Simulador "¿Y si...?"**: Proyección de escenarios de inversión y riesgo.
- 🗓️ **Calendario Productivo**: Integración de clima, ciclos biológicos y referencia lunar tradicional.

## 📱 Uso Rápido

1. Abre el archivo `index.html` en cualquier navegador moderno.
2. Selecciona el perfil (**Ramón**, **Marta** o **Futuro Finquero**).
3. Navega entre las secciones usando el menú inferior.
4. Interactúa con los datos de demostración (fincas *"El Roble"* y *"AgroTech Solutions"*).

---

## 🔧 Instalación en GitHub Pages

1. Sube estos archivos a tu repositorio `abermudezvila08-png`.
2. Ve a **Settings** > **Pages**.
3. Selecciona la rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que se despliegue.
5. Accede a `https://abermudezvila08-png.github.io/tu-repo/`.
